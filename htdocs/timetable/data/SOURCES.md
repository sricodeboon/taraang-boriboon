การแปลงข้อมูล
- ตัดคำนำหน้า จังหวัด/อำเภอ/กิ่งอำเภอ/ตำบล (สำหรับ กทม. ตัด เขต/แขวง) และรวมช่องว่างที่ซ้ำกันให้เหลือช่องเดียว
- เรียงชื่อจังหวัด อำเภอ และตำบล ด้วย `Intl.Collator('th')` ซึ่งเรียงตามพจนานุกรมไทย โดยไม่นับสระหน้า (เ แ โ ใ ไ) เป็นอักษรตัวแรก
- ชื่อตามแหล่งทุกตัว เช่น "ปอภาร (ปอพาน)" "สุไหงโก-ลก" "จ.ป.ร."

สิ่งที่ตัดออก
- ศูนย์พัฒนาเด็กเล็ก ศูนย์อบรมเด็กก่อนเกณฑ์ และศูนย์รับเลี้ยงเด็ก รวม 17,701 แห่ง (ไม่ใช่โรงเรียนที่ต้องจัดตารางสอน)
- สังกัด 12 กศน. (ศูนย์ส่งเสริมการเรียนรู้ระดับอำเภอ) 1,050 แห่ง และสังกัด 55 สถาบันวิชาการป้องกันประเทศ 2 แห่ง
- สังกัด 14 ที่เป็นมหาวิทยาลัย ไม่ใช่โรงเรียนสาธิต 1 แห่ง
- ไม่เก็บข้อมูลติดต่อ เช่น เบอร์โทร อีเมล เว็บไซต์ ที่อยู่ หรือพิกัด และไม่มีชื่อบุคคล เก็บเฉพาะ `n c t a p`

การแปลงข้อมูล
- ชื่อโรงเรียนของ สพฐ./สช./กทม./พศ. ในแหล่งไม่มีคำว่า "โรงเรียน" นำหน้า เราจึงเติมให้ ยกเว้นศูนย์การศึกษาพิเศษ เช่น "บ้านนาทม" เป็น "โรงเรียนบ้านนาทม"
- ชื่อที่ขึ้นต้นด้วย "รร." หรือ "ร.ร." (ส่วนใหญ่มาจาก อปท.) เปลี่ยนเป็น "โรงเรียน"
- ตัวเลขไทยในชื่อคงไว้ตามต้นฉบับ
- `c` คือรหัสสถานศึกษา 10 หลักของกระทรวงศึกษาธิการ ไม่มีรหัสซ้ำ
- `t` `a` `p` ตัดคำนำหน้าแล้วจับคู่กับ geo.json ได้ครบ **36,874 จาก 36,874 (100%)** โดยไม่ต้องเดาอำเภอจากตำบลเลย มี 2 ระเบียนที่จับคู่ได้ด้วยการตัดวงเล็บท้ายชื่อตำบล คือ "ปอภาร (ปอพาน)"
- เรียงชื่อโรงเรียนด้วย `Intl.Collator('th')`
- ชื่อโรงเรียนซ้ำกันได้ภายในจังหวัดเดียว (612 ชื่อ เช่น "โรงเรียนบ้านคลองหิน") เพราะเป็นคนละโรงเรียนในคนละตำบล UI ควรแสดงตำบลและอำเภอประกอบ

ข้อจำกัดที่ทราบ
- ข้อมูลเป็นของปีการศึกษา 2568 โรงเรียนที่ยุบ ควบรวม หรือเปิดใหม่หลังจากนั้นจะยังไม่อัปเดต ผู้ใช้พิมพ์ชื่อเองได้เสมอ
- เมื่อเทียบกับ "รายชื่อโรงเรียนสังกัด อปท. ปี 2569" ของ สถ. (https://data.go.th/dataset/school12, 1,819 แห่ง) มี 169 ชื่อที่ไม่ตรงแบบตัวอักษรต่อตัวอักษร ส่วนใหญ่ต่างกันที่การเขียน เช่น "เทศบาล ๒" กับ "เทศบาล2" และวงเล็บ เราไม่ได้รวมชุดนั้นเข้ามา เพราะไม่มีข้อมูลตำบลและจะทำให้เกิดรายการซ้ำ
- ไม่มีโรงเรียนนานาชาติหรือเอกชนนอกระบบที่ไม่ได้อยู่ในฐานข้อมูลกลางของกระทรวงศึกษาธิการ

## วิธีสร้างใหม่

```bash
cd htdocs/timetable
node tools/build-data.mjs --raw /path/นอก/htdocs/data-raw            # ใช้ไฟล์ดิบที่มีอยู่แล้ว ถ้าไม่มีจะดาวน์โหลด
node tools/build-data.mjs --raw /path/นอก/htdocs/data-raw --refresh  # ดาวน์โหลดใหม่ทั้งหมด
```

- ต้องใช้ Node 18 ขึ้นไป ไม่มี dependency ภายนอก สคริปต์อ่าน .xlsx เองได้
- ค่าเริ่มต้นของ `--raw` คือ `$TMPDIR/sricodeboon-data-raw` สคริปต์จะไม่ยอมทำงานถ้าชี้เข้า htdocs
- สคริปต์เขียน `data/geo.json` และ `data/schools/*.json` ใหม่ทั้งหมด และเขียน `build-report.json` กับ `unmatched.tsv` ไว้ในโฟลเดอร์ raw
- เมื่อ กระทรวงศึกษาธิการ ออกไฟล์ปีใหม่ เช่น school69.xlsx ให้แก้ URL ใน `SRC.moe_school68` แล้วรันใหม่ ถ้าต้องการข้อมูลภูมิศาสตร์ใหม่ ให้แก้ `GEO_COMMIT`
- `tools/` ไม่ต้องอัปโหลดขึ้นโฮสต์
